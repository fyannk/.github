# Support

- **Questions and ideas**: use the repository's Discussions tab when it is
  enabled, otherwise open an issue with the feature request form.
- **Bugs**: open an issue with the bug report form, including versions and
  reproduction steps.
- **Security issues**: follow [SECURITY.md](SECURITY.md), never a public issue.

These projects are maintained by one person in their spare time. There is no
guaranteed response time, and no commercial support.
