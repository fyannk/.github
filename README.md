# fyannk/.github

Shared defaults for every repository under [@fyannk](https://github.com/fyannk).

## Community health defaults

GitHub uses these files for any of my public repositories that does not ship
its own copy. A repository that has its own file always wins.

| File | Purpose |
|---|---|
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to propose a change |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask questions |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) | Bug report and feature request forms |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Pull request checklist |
